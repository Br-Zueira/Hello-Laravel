# Hello-laravel

## About Hello-laravel
Hello-laravel is a personal project by Br-zueira (me) meant to be a practical way to learn web frameworks such as Laravel and Tailwind CSS, mainly backend focused. Its idea is to provide unhinged and funny excuses to diverse embarassing or complicated situations, such as accidentally deleting your company's whole database or not doing your virtual homework because 'your dog ate your computer', evaluating the excuses and situations by:

* **Risk score:** Scale from 1 (Minor embarassment) to 10 (Going to be kicked out forever from society)
* **Believability rate:** Percentage from 0-100% of the excuse
* **Category:** Domain, such as school or work
* **Chaos score:** An equation to define how out-of-control is the situation. The bigger the result, the more chaotic it all is. Evaluated as: risk score + (100 - believability rate). 

### Tools:
* Backend: Laravel (PHP) - The coolest stuff, everything 100% made specifically for this project: Routes, Data managment, Logic, etc
* Fronend: Tailwind CSS and TomSelect library - The part that is cool until we need to centralize a <div> or make dynamic page interaction

### Note
As you can see, this project was made just to fun and learn and is totally memey and unhinged, so don't expect nothing great, and I hope you have fun with this project just like I had doing it.
